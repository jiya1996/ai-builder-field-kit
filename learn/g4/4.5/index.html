01

复用不是复制旧项目

通用认证、错误状态、日志和发布流程可以进入 Starter Kit；业务字段、历史数据和特定用户假设必须删除或参数化。

02

SOP 与 Skill 都需要触发和停止条件

一份可靠流程不仅写步骤，还要说明何时使用、需要什么输入、遇到什么情况停止，以及怎样验证输出。

03

作品集卖的是判断证据

案例页要说明问题证据、范围取舍、系统设计、失败与修复、用户结果和下一步，而不是只放漂亮截图。

这关杀死哪个焦虑

"白学了"的前一半。 做完一个项目却发现下一个还是从零开始——那才叫白学。本关把关卡2 里被验证过的一切资产化：下次开工，登录、数据库、上传、AI 调用、验收清单全部现成，你只做新产品独有的那 30%。

时间账（写在墙上）：关卡2 你用了约 15–17 天；本关目标：第二个同复杂度产品 ≤7 天。减半不靠手速，靠不重复付已付过的学费。

3.2打造自己的 Starter Kit第 2–3 天展开正文
输入

已分类的可复用清单，以及第一个产品中通过验证的通用模块。

空白环境可启动的 Starter Kit v1。

白话讲清

Starter Kit = 一个可一键复制的模板仓库：新项目从它出发，登录/数据库连接/上传/AI 调用/错误处理/验收文档已经就位。它不是"框架"，是你自己验证过的最小起点。写清适用范围同样重要：适用于"多用户 + Supabase + 一项 AI 能力"的中小 Web 应用；不适用于小程序、重实时协作、大数据量场景——知道边界的模板才敢复用。

3.3把稳定流程做成 SOP / Skill第 3 天展开正文
输入

至少在一个真实项目中跑过的流程、常见坑记录和对应验收方法。

动手做

制作项目启动、上线前检查、故障排查三张 SOP。

完成证据

3 张带触发条件、步骤、停止条件和验证记录的 SOP。

白话讲清

代码之外，流程也能资产化。把你重复做过 ≥2 次且步骤稳定的流程写成 SOP 卡；如果你的 Coding Agent 支持 Skill/自定义命令，就再包装成一条命令。格式（军火库 AR-2 附模板）：

名称：上线前检查
触发条件：任何项目准备部署到 Production 前
输入：项目仓库
步骤：1) 本地 build 通过 → 2) 安全七条自查 → 3) 生产环境变量核对表 → 4) 部署 → 5) 线上验收单
检查点：每步的证据是什么
停止条件：任何一步不通过，停止并进急救室，不带病上线

先做三张最值钱的：上线前检查、新功能验收、排错求助。原则：只固化验证过的，保留人工判断——SOP 是护栏，不是自动驾驶；没做过两次的流程不配成为 SOP。

  • 三张 SOP 卡入库（放进 Kit 的 docs/sops/）

4.3独立交付第 4–12 天展开正文
输入

通过评审的规格与架构、任务卡、Starter Kit 和明确的上线验收条件。

动手做

完成核心流程、AI 能力、安全加固、上线与一次迭代。

完成证据

生产链接 + 完整工程与运行证据链。

规则很短：

  1. 从你的 Starter Kit 出发；任务卡与 SOP 照常使用。
  2. 每个里程碑发一次进度帖（产物截图 + 卡住的问题）——公开进度是最便宜的防烂尾机制。
  3. 验收标准与关卡2 完全一致：两张验收单、安全七条、越权测试、线上验收、回滚演练，一项不少。
  4. 卡住 → 急救室 → 标准求助模板。毕业关卡住是常态，独立 ≠ 孤立。
  • 4 个里程碑帖 + 全套验收证据 + Production 链接
4.4案例页与面试叙事包第 12–13 天展开正文
输入

产品链接、用户问题证据、关键取舍、测试结果、失败记录和迭代数据。

动手做

写案例页、30 秒介绍、STAR 故事和简历条目。

完成证据

公开案例页 + docs/INTERVIEW.md。

案例页（一页，放在你的个人主页或 README 顶部）

固定结构（模板见军火库 AR-7）：

  1. 问题：谁的什么麻烦 + 一条最有力的验证证据
  2. 方案：一张产品截图 + 核心流程一句话 + 架构图
  3. 证据：真实用户数 / 一条真实反馈 / 越权测试与回滚演练通过（放证据截图，这是别人作品集里没有的东西）
  4. 复盘：一个技术决策及其取舍、一个我修过的最难的坑、下一步

面试叙事包（docs/INTERVIEW.md）

  • 30 秒版：我发现了__的__问题，做了__，现在有__个真实用户，我能重复交付这类产品（有 Starter Kit 为证）。

  • 3 分钟 STAR 版：情境（问题与证据）→ 任务（范围与约束）→ 行动（关键决策 3 个，含一次排错故事）→ 结果（用户/反馈/迭代/时间对比图）。

  • 追问弹药：为什么选这个栈 / RLS 是什么、你怎么测的 / 成本怎么算 / 如果重做会改什么。

  • 简历条目模板：独立交付多用户 AI 应用「__」：需求验证（5 访谈）→ 上线（Next.js+Supabase）→ __ 名真实用户；建立个人 Starter Kit，第二个产品交付时间缩短 __%。

  • 案例页上线 + 叙事包完成，并做一次 3 分钟模拟讲述（社群互练）
