不要只看

代码块、提示词和检查框都是本节任务的一部分。

跟我做

沿用关卡1 的三件套开工：初始化项目、写 AGENTS.md（把 2.1 的 PRODUCT.md 和铁规矩接上）、首个提交。然后一张任务卡：

【任务】完成灵感罐头的页面骨架（先不接数据库和登录，全部用写死的假数据）
【页面清单】
1. /login 登录页（表单先摆着，不校验）
2. / 罐头列表页：网格卡片展示 6 条假灵感（字段：内容摘录、类型 文字/链接/图片、
   标签、创建时间），顶部有"新建灵感"按钮和标签筛选条
3. /new 新建页：一个大输入框 + 图片选择占位 + 保存按钮（点击后跳回列表）
【验收条件】三个页面能互相跳转；列表页手机宽度单列显示；空/加载状态占位齐全
【范围】不接 Supabase，不引入大型 UI 库

逐条验收，提交。壳先行的理由和关卡1 相同：AI、数据库、登录接进来之前，壳必须是确定可用的。

验收

  • 三页可跳转，假数据显示正常，手机宽度可用
  • git 已提交（本关起不再提醒，默认每个任务卡完成即提交）
