白话讲清

Starter Kit = 一个可一键复制的模板仓库：新项目从它出发，登录/数据库连接/上传/AI 调用/错误处理/验收文档已经就位。它不是"框架"，是你自己验证过的最小起点。写清适用范围同样重要：适用于"多用户 + Supabase + 一项 AI 能力"的中小 Web 应用；不适用于小程序、重实时协作、大数据量场景——知道边界的模板才敢复用。

跟我做

【任务】把关卡2 项目蒸馏成 Starter Kit
【实现】
1. 复制一份项目，删除"灵感罐头"业务：去掉具体页面文案与字段，保留
   登录闭环 / 一张示例表（items）+ 完整 RLS 四策略 / 文件上传模块 /
   /api/ai 通用调用骨架（含结构化输出校验、频率限制、日志用量打印）/ 三状态壳组件
2. 内置 docs/：AGENTS.md 模板、PRODUCT.md 模板、任务卡模板、全部验收清单
3. 写 README：这是什么 / 适用与不适用 / 从零跑通四步（克隆→装依赖→配环境变量→起服务）
   / 环境变量清单表（每个变量：名字、去哪里拿、放哪层）
4. 推到 GitHub 新仓库 my-starter-kit，设为模板仓库
【验收】见 3.5 Boss 战——现在先自测一遍四步能跑通
