01

七类产品不是七种界面

Deep Research 的核心是来源与综合；Data 产品重计算与可验证结果；Browser 和 Coding 产品重 Runtime、权限和恢复。

02

Personal 与 Knowledge 的边界在数据关系

个人助手重长期偏好、任务和隐私；知识产品重资料摄取、检索、引用和更新。二者都需要记忆，但数据生命周期不同。

03

Workflow Automation 的价值是可重复执行

它连接触发器、系统和审批，把确定流程自动化；只有无法预先确定下一步时，才在局部引入 Agent。

输入

Starter Kit v1、三张 SOP、计时表和核心流程不同的第二个选题。

动手做

用 Kit 做打卡圈、反馈墙、书签夹或同等复杂度产品。

完成证据

第二产品链接 + 全程耗时与错误记录。

选题（同样三选一，或自拟同复杂度题）

要求与关卡2 同构（登录 + CRUD + 隔离 + 一项 AI 能力 + 上线），核心流程必须不同：

  • A. 周报生成器 Pro：团队成员各自提交本周要点，AI 汇总成周报（多用户 + 汇总型 AI）。
  • B. 面试题闪卡：自建题库，AI 出追问和评分（CRUD + 评估型 AI）。
  • C. 小店留言簿：给你朋友的小店做一个客户留言 + AI 情感归类（真实客户 = 更硬的用户证据）。

规则

  1. 从你的 Starter Kit 模板仓库创建，不从零建。
  2. 全程用任务卡驱动，沿用三张 SOP。
  3. 每天记录用时（诚实记录，含排错时间），最后画对比图：关卡2 各环节用时 vs 本项目各环节用时。
  4. 验收标准不打折：两张验收单 + 越权测试 + 线上验收，一项不少。
  • 第二个产品上线，验收全套通过
  • 时间对比图完成（哪个环节省得最多？哪个环节没省？为什么？）
学完必须掌握
  • 能按系统难点而不是界面给产品分类
  • 能识别每类产品的核心风险
  • 能从参考 Repo 提取可复用模式而非照抄功能
