S06

Agentic 系统

什么是 Agent，Harness 又如何把模型回答变成受控行动？

本阶段要做的东西亲手搭建一个只允许有限工具、保留完整 Trace 的白盒 Agent。
理论学习
7–9 小时
实战周期
4–7 天
输入什么

一个需要多步判断、工具调用和反馈循环的开放任务。

输出什么

可观察、可授权、可停止、可回放的最小 Agent 系统。

学会什么

解释谁决定调用、谁真正执行、谁授权、状态在哪里以及系统为何停止。

KNOWLEDGE

不是记名词，而是理解系统因果。

本阶段只学习马上会在项目中使用和验证的知识。

Model BoundaryTool SchemaTool Call / Tool ResultManual LoopHarnessRuntimePermissionStateTrace / ReplayMCPAgent SDK
01

Agent 是反馈循环，不是更长提示词

模型观察当前状态、选择下一步或工具、获得执行结果，再继续判断，直到完成、失败或触发停止条件。

02

Tool Call 不等于 Tool Execution

模型只能生成调用意图。Harness 校验参数、检查权限并把动作交给 Runtime；执行结果再作为 Tool Result 返回模型。

03

Harness 是模型外的控制系统

它负责上下文、工具注册、权限、状态、Trace、预算、停止、恢复和人工审批。模型负责判断，但不应自行拥有无限执行权。

Agent 与 Harness：从模型回答到系统行动

进入一次完整 Run，分清模型、Agent、Harness、Runtime、Tool Call 与 Tool Execution，并完成最小验证实验。
